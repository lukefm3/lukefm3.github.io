Methodology

Designed to be replaced.

The R script downloads the USGS “all earthquakes, past day” GeoJSON feed, checks its structure, converts selected fields to a clean CSV, and writes update metadata. The browser reads only those generated files.

To adapt this, change the source URL and parsing block in R/update_earthquakes.R, then revise the labels and field names in docs/assets/dashboard.js.
